# 被动生成速度与交互稳定性验收

日期：2026-10-27。范围为当前工作区的被动 TPS、新增的动态下拉更新方式及已复现的滚动/展开问题；不代表全软件所有交互均已覆盖。

## 功能与口径

- 实际代理请求结束后保存 `generationSpeed`，来源列表返回各模型最近至多 20 条有效样本的中位数；没有主动测速或额外生成请求。
- 思考、正文和工具参数合并，真实上游用量优先。中文真实用量不乘校准系数；缺失计数时复用已有文字估算和模型校准，并明确标记估算。
- 可见流测量内容分片间的输出速度，并扣除首个分片的 token 估计份额；隐藏思考和非流式 JSON 单独采用上游请求窗口，显示“含首包等待”。
- 样本按实际来源、配置代次、来源模型/上游模型、思考强度、服务档位、估算与计时口径隔离。失败、取消、短输出和缓冲单分片不进入正常统计。

## 已复现并修复的交互问题

| 问题 | 修复前证据 | 修复后证据 |
| --- | --- | --- |
| 专注统计下拉框突然关闭 | 延迟报表响应到达后，“会话阶段”原控件断开连接，新控件关闭 | 原节点、展开状态和键盘焦点保持；滚动位置 532.5px → 532.5px |
| 扩展列表滚动回到顶部 | 首行保有焦点，用户滚到 1200px，刷新后焦点恢复导致 1200px → 0px | 内容不变保留原节点；内容变化后恢复焦点时仍为 1200px |
| CLI 默认模型菜单被相邻筛选重建 | `renderActions` 每次替换整个默认模型字段 | 实际 CLI 页面组件中搜索触发重绘，菜单保持展开和焦点，页面 2059px → 2059px，菜单滚动 163px → 163px |

公共 `updateSelectField` 还验证了未挂载容器的值更新、选项相同不换节点、选项变化保留活动项/菜单滚动/焦点、选择只发一次 change，以及禁用后正确关闭。公共弹窗与抽屉恢复焦点使用 `preventScroll`。输入和下拉使用共享颜色/圆角变量，菜单使用统一选中色和滚动边界隔离。
