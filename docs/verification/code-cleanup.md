# 无用代码与旧样式清理

2026-10-16，基于 0.5.0 发布后的 main 清理。源码、测试和浏览器均使用隔离数据；未替换本机 App，未重建或修改已发布的 DMG。

## 清理范围

- 删除未调用的六个 utils 函数、`assembleResponse`、`defaultContextLength`、进程模块的 `exec` 及专属 import、Qoder 编码模块的 `__internal`。
- Qoder 请求编码、COSY 签名仍在生产模块；反向解码和 AES 解密断言辅助代码移至 `fixtures/qoder/wire.mjs`，保留原协议测试。
- 注册表只调用来源 `execute`；事件测试复用 `fixtures/proxy/provider.mjs`，原生响应测试直接声明 response 结果。删除旧 `forward/stream` 猜测分支、只被测试使用的 router.stream 与 relay(provider)。重试、参数错误、部分输出、取消和会话绑定继续通过实际网关或当前接口验证。
- 将 `thinkingLevels`、`classifyError`、`errorHints` 收为模块内部符号。
- 删除旧 AGY/Grok 额度控件、自定义模型旧控件和旧项目侧栏样式，共移除 94 个选择器分支；混合选择器保留有效分支。公共按钮的动态变体、当前公共额度和模型组件保留。

保留旧管理 API 与 AI 配置资源映射、AGY 登录只读导入、旧单 Key 配置、数据目录迁移、历史回执及 Provider 内部必要协议差异。没有移除 MCP/Qoder SDK 或其传递依赖。

原生任务检查的临时测试构建使用 get-only 空凭据助手，结束后恢复原助手并再次校验签名；共用契约测试首次受后台外网发现影响导致退出超时，屏蔽外网后通过。上述验证没有使用真实账号推理，Pi 使用模拟授权和上游，不替代此前的真实账号验证。

首次远端 CI 在 Agent API 测试删除临时目录时出现 `ENOTEMPTY`：旧测试只关闭 HTTP listener，未等待后台服务关闭，并启动了与任务验收无关的来源发现。Agent API 测试现复用 `fixtures/workbench.mjs`，隔离代理/Pi/扩展目录、禁用真实来源与价表发现，重启和结束都先等待服务关闭，再删除临时目录；任务、鉴权、去重、撤销和 Skill 断言保留。修正后本地 456 项回归及该文件连续 5 次重复运行通过。

结束时核对的 36 个本机业务、Pi、扩展及私有 OAuth 配置文件摘要一致，已安装 App 文件与发布 DMG 保持原样。五个独立来源账号身份均一致；其中 Kimi 凭据摘要发生变化，其余四份不变，没有调用真实账号的登录、退出或刷新管理接口。测试构建已清理，dist 中的原 0.5.0 App 及构建摘要已恢复，避免与已发布安装包混淆。
