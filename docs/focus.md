# 日历与专注

任务页提供全部、今天和日历三种范围，侧栏提供独立的专注统计页。日历按日期引用已有任务，支持项目、状态、关键词筛选；选择未来日期新建任务只加入该日期。改期将任务从来源日期移到目标日期，目标已有引用时保留一个，任务状态和其他日期安排保留。日历移出和排序同样保留任务执行状态；旧 API 默认行为见 [接口说明](../skills/daylight-workbench/references/api.md)。

## 开始与控制

任务详情、今天页和全局专注条可以打开计时面板。工作计时必须关联一个当前未完成任务，默认 25 分钟；短休息默认 5 分钟，可以不关联任务。设置支持工作 1–180 分钟、短休息 1–60 分钟。已有计时的目标时长在开始时固定，修改默认设置只影响下一轮。

开始专注不改变任务的 todo/active/done 状态，不自动加入今天。暂停冻结本轮剩余时间，继续打开新的有效计时段；提前结束保留已经过的有效时间。切换任务需确认提前结束旧轮，再开始新轮。到期只归档本轮，不自动启动休息或下一轮，也不自动完成任务。

任务完成、任务删除或所属项目删除后，关联工作会话自动结束。任务写入先成功，随后核对专注；专注保存失败会提示并重试，不把已经成功的任务写入回滚。撤销任务操作不复活已经归档的会话。专注操作不进入任务撤销历史。

## 经过时间与恢复

计时使用服务端墙上时间，记录有效运行段；网页每秒显示倒计时，服务端独立处理到期。关闭网页或原生主窗口不会暂停。系统睡眠和退出 App 期间仍经过时间；重启或唤醒后核对，到期最多计入本轮目标时长。App 退出期间无法准时发通知。

暂停段不计时。系统时钟明显回拨会冻结会话并标记时间异常，按最后可信时间闭合运行段。用户可以结束本轮；继续或开始新轮须等系统时间恢复到可信截点后。异常会话不计为正常完成。该指标表达计时经过时间，不能据此推断人是否实际工作。

页面可能离线或处于保存重试状态，此时保留服务端状态并提示。界面不会因为本地倒计时到零自行生成成功记录。版本冲突需读取最新会话重新判断；写结果未知时只核对原请求。

## 统计口径

统计页提供今天、近 7 天、近 30 天和自定义范围，包含工作经过时间、正常完成轮数、提前结束及异常结束次数，按日、开始时项目归属汇总，并分页显示会话。日期范围两端包含在内，最多 366 天。休息经过时间单独统计，不进入工作轮数。

有效运行段跨午夜时拆到各日期；完成轮数归到结束日期。统计时区在首次创建专注文件时取系统 IANA 时区，随后固定，界面显示该时区。系统旅行或时区设置变化不会改写历史。项目统计使用开始时项目 ID/名称快照；任务累计按稳定 taskId 汇总全部历史，任务改名、移项目或删除不改写历史记录。

未归档的当前工作会话计入已发生的有效时间，并标记包含当前会话。统计与打开的任务累计在关联工作运行期间每 15 秒刷新；隐藏页面停止额外报表刷新，恢复可见时核对。会话分页游标与专注版本、筛选绑定，版本变化后需从第一页重查。

## 提醒与 macOS

网页服务仅提供打开页面内的到期反馈。原生 App 使用系统通知，并在菜单栏显示本轮计时、暂停/继续/结束及开始入口。菜单展开时保留菜单内容，计时文本单独刷新；关闭主窗口继续驻留。

只有在设置页明确点击请求授权时才调用系统通知授权。通知权限被拒绝不影响计时、归档或统计，可从设置页打开系统通知设置。专注设置的提醒/声音开关与 OS 授权分别表示，AI 修改设置不会弹出授权框。

系统通知在会话成功归档后才投递。通知消费先持久保存 attempted，再调用 OS 并保存 scheduled/failed；崩溃恢复不会重复投递已尝试的旧通知。系统通知关闭、免打扰、系统策略和 App 退出可能影响提醒展示，页面保留本轮结果。

## 文件与维护边界

任务继续使用 schema 1 的 state.json。专注独立保存于同一数据目录下的 focus.json，包含 schema/version/settings/current/sessions/lastOutcome/receipts；focus.previous.json 保留上一版成功数据，文件权限为 0600。历史不裁剪、不保存权威累计数，统计由会话重算。超过 10 MiB 时设置页显示历史规模诊断，仍保留全部记录。

专注格式或时区异常时，专注接口返回不可用，保留原文件；任务、AI 和代理模块仍可独立使用。没有自动修复或导入 UI。需要手动恢复时先退出服务并保存现有文件副本，再将 focus.previous.json 复制为 focus.json；任务数据无需同时恢复。同一数据目录只由一个运行实例写入。
